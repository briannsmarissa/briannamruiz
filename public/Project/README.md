# Enterprise GRC Risk Management Portfolio

## Overview

This repository demonstrates a mock Governance, Risk, and Compliance
(GRC) project simulating an enterprise risk assessment.

## Repository Contents

-   **Mock_GRC_Risk_Register.xlsx** -- Enterprise risk register with
    risk scoring, controls, mitigation plans, owners, and framework
    mapping.
-   **Mock_Risk_Assessment_Report.pdf** -- Executive summary,
    methodology, findings, and recommendations.

## Frameworks

-   NIST Cybersecurity Framework (CSF)
-   CIS Controls v8
-   SOC 2 Trust Services Criteria

## Skills Demonstrated

-   Enterprise Risk Assessment
-   Risk Register Development
-   Risk Scoring
-   Control Evaluation
-   Risk Mitigation Planning
-   Governance Documentation
-   Third-Party Risk
-   Identity & Access Management (IAM)
